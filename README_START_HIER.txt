PROJEKT NEUER KAMP – VERSION 3

1. ZIP vollständig entpacken.
2. index.html öffnen.
3. Alle HTML-Seiten enthalten noindex, nofollow, noarchive.
4. Webseite ist dennoch öffentlich zugänglich, sobald sie bei GitHub Pages veröffentlicht wird.
5. QR-Code erst nach Festlegung der endgültigen GitHub-Pages-Adresse erstellen.
6. Vor Veröffentlichung: Impressum/Datenschutz vervollständigen und rechtlich prüfen.
7. Bitte keine robots.txt mit Disallow: / anlegen: Suchmaschinen müssen noindex lesen können.
